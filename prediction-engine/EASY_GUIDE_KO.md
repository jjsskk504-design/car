# 쉽게 이해하는 PRISM 궤적 예측 엔진

## 이 프로그램은 무엇을 하나요?

도로 위 자동차를 점이라고 생각해 보겠습니다. 카메라나 시뮬레이터가 1초마다 그 점의 위치와 속도를 알려주면, 이 엔진은 “이 움직임이 이어진다면 1초 뒤, 2초 뒤, …, 5초 뒤 어디쯤 있을까?”를 계산합니다.

중요한 점은 **위험하다고 판단하지 않는다는 것**입니다. 이 엔진은 미래 위치 후보만 만듭니다. 위험 등급은 다음 단계의 별도 엔진이 판단합니다.

## 좌표를 읽는 법

내 차 운전석에서 앞을 본다고 생각하면 쉽습니다.

```text
                 y+ (앞)
                    ↑
       x- (왼쪽) ← 내 차 → x+ (오른쪽)
                    ↓
                 y- (뒤)
```

- 위치 `x=3, y=20`: 내 차 오른쪽 3m, 앞쪽 20m
- 속도 `vx=0, vy=5`: 옆 이동 없이 초당 5m씩 전진
- `heading_rad≈1.57`: +x축에서 반시계 방향으로 90도, 즉 앞쪽을 향함
- `timestamp_ms=2000`: 시나리오가 시작된 지 2초

## 왜 과거 좌표를 다시 맞추나요?

내 차도 움직이기 때문입니다. 2초 전 내 차에서 보던 “앞 20m”와 지금 내 차에서 보는 “앞 20m”는 실제 도로의 같은 위치가 아닙니다. 그래서 과거의 모든 차량 위치를 **현재 내 차에 붙인 한 장의 모눈종이** 위로 옮긴 뒤 속도와 가속도를 비교합니다.

이 작업은 `coordinates.py`와 `history.py`가 맡습니다. 자차의 정확한 절대 위치가 제공되면 그것을 사용하고, 없으면 속도와 방향 변화로 추정합니다. 추정값은 측정값보다 오차가 클 수 있습니다.

## 네 가지 후보는 무엇인가요?

예측은 정답 하나를 단정하지 않습니다.

1. `lane_keep`: 지금 움직임을 이어 차선을 유지
2. `braking`: 속도를 줄이다가 정지
3. `lane_change_left`: 부드럽게 왼쪽 차선으로 이동
4. `lane_change_right`: 부드럽게 오른쪽 차선으로 이동

`confidence: null`은 오류가 아닙니다. 실제 데이터로 확률을 보정하지 않았기 때문에 70%, 80%처럼 근거 없는 값을 쓰지 않았다는 뜻입니다.

## CV와 CA의 차이

- CV는 “속도가 계속 같다”고 봅니다. 초속 5m라면 2초 뒤 10m를 더 갑니다.
- CA는 “속도가 얼마나 변하고 있는지”까지 봅니다. 매초 2m/s씩 느려졌다면 앞으로도 같은 감속이 잠시 이어진다고 계산합니다.

CA에 필요한 과거 관측이 부족하면 프로그램은 멈추거나 0을 채우지 않고 CV로 폴백합니다.

## 직접 실행해 보기

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\prism-predict.exe export --input examples\vehicle_frames.jsonl --output build\my_prediction.json
```

완료 후 `build\my_prediction.json`을 열면 `car_01` 아래에 네 후보와 1~5초 뒤 점들이 보입니다.

## 어디까지 믿어야 하나요?

이 버전은 설명 가능하고 재현 가능한 P0/P1 기준선입니다. 실제 도로 지도, 운전자 의도, 신호, 센서 오차를 모두 아는 인공지능이 아닙니다. 특히 급격한 끼어들기, 미끄러짐, 센서 ID 변경에는 오차가 커질 수 있습니다. 따라서 실제 차량 제어 또는 충돌 방지 장치로 사용하면 안 됩니다.
